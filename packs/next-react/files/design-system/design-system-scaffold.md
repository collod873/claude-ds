# design-system-scaffold

How to add a new component to the design system.

## Trigger the skill

Say "new atom", "new composite", or "scaffold component" to Claude. The
`scaffold-component` skill will guide output.

## Required file bundle

Every component ships as:

```
design-system/atoms/<Name>.tsx        ← hand-authored; meta export required
design-system/atoms/<Name>.showcase.tsx   ← generated by hook on first save
design-system/atoms/<Name>.states.json    ← generated by hook on first save
design-system/atoms/<Name>.test.tsx       ← hand-authored; not generated
```

(Use `composites/` instead of `atoms/` for composites.)

`.showcase.tsx` and `.states.json` are generated automatically by
`regenerate-companions.sh` (PostToolUse hook) on first save of `<Name>.tsx`.
Do not create them manually.

## meta export

Every `<Name>.tsx` must export:

```ts
export const meta: Meta = {
  kind: "atom", // or "composite"
  examples: [{ name: "Default", props: {} }],
};
```

See `design-system/types/meta.ts` for the full `Meta` discriminated union.

## Legacy slash commands (obsolete)

`build-component` and `close-component` slash commands in `.claude/commands/`
are obsolete as of v0.6.0. The companion generation they handled is now
automatic. Delete them if present:

```
rm .claude/commands/build-component.md
rm .claude/commands/close-component.md
```
