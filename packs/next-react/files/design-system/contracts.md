# Design-system contracts

- Atoms may not import from composites.
- Color values must come from `tokens.json`; raw hex is forbidden in design-system files.
- Failures are logged to `failure-log.md` via `.claude/hooks/lib/log-failure.sh`.

## Per-component bundle

Every component — atom or composite — ships as:

```
<Name>.tsx
<Name>.showcase.tsx
```

The `.tsx` is hand-authored; `.showcase.tsx` is regenerated by the
PostToolUse hook into a mirror of the component's `meta.examples`. There is
no per-component `.test.tsx`: behavior is verified by the shared **role
contracts** in `design-system/contracts/roles/`, run via
`design-system/contracts/role-contracts.test.tsx` (ADR-0016). A component
opts in by declaring `meta.role`.
