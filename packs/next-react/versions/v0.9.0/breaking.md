# v0.9.0 Breaking Changes

## Managed manifest generator

`design-system/manifest.generated.ts` is now generated by the pack-managed
`scripts/build-manifest.ts` and must not be hand-edited. If your project had a
hand-built `manifest.generated.ts`, the `manage-manifest` migration Op deletes
it; the PostToolUse hook regenerates it on the next component file write.

Run `node --experimental-strip-types scripts/build-manifest.ts` to regenerate
immediately after upgrading.

## @/* alias hardcoding resolved (#52)

`build-manifest.ts` now emits relative imports (`./atoms/Button.showcase`)
instead of `@/design-system/...` paths, so the generated module works in both
`app/` and `src/app/` Next.js layouts without any tsconfig alias dependency.

## Migration Ops

- `manage-manifest@v0.9.0` — installs pack-managed `scripts/build-manifest.ts`;
  deletes any consumer hand-built `design-system/manifest.generated.ts`.
