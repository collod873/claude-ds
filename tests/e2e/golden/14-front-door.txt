Usage: claude-ds [options] [command]

Design-system governance & scaffold CLI.
Run `claude-ds` with no command to start: first run greets and routes you to
init/adopt;
an adopted project shows a health dashboard. The commands below are the
explicit onramps.

Options:
  -V                        output the version number
  --answers <file>          JSON bag of pre-supplied Decision answers
                            (ADR-0016) — used by the first-run greet
  --verbose                 show the full per-file change list in the
                            commitment-gate preview (default: per-tier summary)
  -h, --help                display help for command

Commands:
  version [options]         print installed vs. latest version
  init [options]            greenfield bootstrap — full scaffold, hooks in
                            BLOCK mode
  audit [options]           read-only conformance report (--fix auto-remediates
                            deterministic issues)
  adopt [options]           brownfield install — scaffold + hooks in WARN mode
  migrate [options] <path>  move one component into the scaffold (registers an
                            exception only when --tier forces a misplacement)
  enforce [options]         flip hooks WARN → BLOCK (gated on exception-count
                            threshold)
  sync [options]            update managed files to the pinned release (diff +
                            confirm)
  doctor [options]          health check — lookalikes, drift, hook verification
  migrate-layout [options]  rename lookalike files to canonical paths (git mv)
  reconform [options]       fill missing companion files and run conformance
                            checks
  reconcile [options]       prune orphaned/deprecated files
  upgrade [options]         bump the pinned version in .claude-ds.json
  classify [options]        categorize existing files into DS tiers
  heal [options]            loop sync → upgrade → classify → audit --fix until
                            convergence (max 3 iterations)
